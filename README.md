## 🔍 Overview
<p>This repository contains hands-on PostgreSQL database practice, covering everything from database creation to advanced SQL concepts like joins, functions, views, triggers, and foreign keys.</p>

 ### It is designed for:
- Beginners learning SQL & PostgreSQL
- Backend developers practicing real-world queries
- Understanding relational database concepts clearly
- The project demonstrates clean SQL syntax, practical examples, and real-use cases commonly used in backend development.
  
<p> Table Creation: PostgreSQL will always generate the eid automatically.You cannot manually insert a value for this ID.</p>

```sql
CREATE TABLE contact (
  eid INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  name VARCHAR(50),
  email VARCHAR(50),
  mob VARCHAR(10),
  age INT,
  city VARCHAR(50)
);
```
<p> PostgreSQL automatically generates the ID, but you can also provide your own ID manually if needed. </p>

```sql
CREATE TABLE contact (
  eid INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name VARCHAR(50),
  email VARCHAR(50),
  mob VARCHAR(10),
  age INT,
  city VARCHAR(50)
);
```

### Salary Queries {Aggregate Functions}
```sql
SELECT MAX(salary) FROM contact; -- Highest Salary
SELECT MIN(salary) FROM contact; -- Lowest Salary
SELECT AVG(salary::numeric) FROM contact; -- Average Salary
SELECT SUM(salary::numeric) FROM contact; -- Total Salary
SELECT COUNT(*) FROM contact;  Total Employees
SELECT name, salary FROM contact WHERE salary = (SELECT MAX(salary) FROM contact); -- Highest Salary Employee
SELECT name, salary FROM contact WHERE salary = (SELECT MIN(salary) FROM contact); -- Lowest Salary Employee
```

### INNER JOIN (Most Commonly Used)
**INNER JOIN** returns only the records where the matching values exist in both tables.
```sql
-- Display menu details with matching food group and quantity type
SELECT
    m.menu_name,
    m.menu_price,
    fg.group_name,
    q.qty_type
FROM menu m
INNER JOIN food_group fg
    ON m.gid = fg.gid
INNER JOIN qtymast q
    ON m.qid = q.qid;
```
**LEFT JOIN** returns all records from the **left table (`menu`)**. If no matching record is found in the **`food_group`** table, the `group_name` column will contain `NULL`.

```sql
-- Display all menu items with their food group (if available)
SELECT menu_name, menu_price, group_name
FROM menu
LEFT JOIN food_group
ON menu.gid = food_group.gid;
```
**RIGHT JOIN** returns all records from the **right table (`food_group`)**. If no matching record is found in the **`menu`** table, the `menu_name` and `menu_price` columns will contain `NULL`.

```sql
-- Display all food groups with their menu items (if available)
SELECT menu_name, menu_price, group_name
FROM menu
RIGHT JOIN food_group
ON menu.gid = food_group.gid;
```
**CROSS JOIN** returns the Cartesian product of both tables. Every row from the **`menu`** table is combined with every row from the **`food_group`** table.

**Example:** If the `menu` table has **5 rows** and the `food_group` table has **3 rows**, the result will contain **15 rows**.

```sql
-- Combine every menu item with every food group
SELECT menu_name, menu_price, group_name
FROM menu
CROSS JOIN food_group;
```
**UNION** combines the results of two `SELECT` statements into a single result set and removes duplicate values.

```sql
-- Combine food group names and quantity types into a single result
SELECT group_name FROM food_group
UNION
SELECT qty_type FROM qtymast;
```
**UNION ALL** combines the results of two SELECT statements into a single result set and keeps duplicate values.
```sql
-- Combine food group names and quantity types into a single result (including duplicates)
SELECT group_name FROM food_group
UNION ALL
SELECT qty_type FROM qtymast;
```

##  Step 1: Create a Backup Table

Create a table to store deleted records from the `contact` table.

```sql
-- Create a backup table
CREATE TABLE back_contact (
  back_id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  emp_id INT,
  name VARCHAR(50),
  email VARCHAR(50),
  mobile VARCHAR(10),
  age INT,
  city VARCHAR(50),
  salary NUMERIC,
  department VARCHAR (50)
);
```

##  Step 2: Create a Backup Function

Create a trigger function that copies the deleted record into the backup table.

```sql
-- Create a function to back up deleted records
CREATE OR REPLACE FUNCTION backup()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO back_contact(emp_id,name, email, mobile, age, city, salary, department)
  VALUES (OLD.eid, OLD.name, OLD.email, OLD.mobile, OLD.age, OLD.city, OLD.salary, OLD.department);

  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```
##  Step 3: Create a Trigger

Create a trigger that automatically runs the backup function before a record is deleted.

```sql
-- Create a trigger for automatic backup before delete
CREATE TRIGGER backup_trigger
BEFORE DELETE
ON contact
FOR EACH ROW
EXECUTE FUNCTION backup();
```
##  View Function

Display the source code of the trigger function.

```sql
-- View the backup function definition
SELECT pg_get_functiondef('backup()'::regprocedure);
```
##  Test the Trigger

Delete a record from the `contact` table.

```sql
-- Delete a record from the contact table
DELETE FROM contact
WHERE eid = 8;
```

## 📝 Notes
When a record is deleted from the `contact` table, the **`BEFORE DELETE`** trigger automatically executes the `backup()` function. The deleted record is copied to the `back_contact` table before it is removed from the original table.

## step 1. Cretate audit table 
Create a table to store audit logs whenever a new record is inserted into the `contact` table.

```sql
-- Create an audit table
CREATE TABLE audit (
    audit_id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    emp_id INT,
    entry_date TIMESTAMP
);
```
##  Step 2: Create an Audit Function

Create a trigger function that logs every new record inserted into the `contact` table.

```sql
-- Create a function to log inserted records
CREATE OR REPLACE FUNCTION auditlog()
RETURNS TRIGGER AS $$
BEGIN
INSERT INTO audit(emp_id, entry_date)
VALUES (NEW.eid, CURRENT_TIMESTAMP);
RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```
##  Step 3: Create a Trigger

Create a trigger that automatically executes the audit function after a new record is inserted.

```sql
-- Create a trigger for automatic audit logging
CREATE TRIGGER audit_trigger
AFTER INSERT
ON contact
FOR EACH ROW
EXECUTE FUNCTION auditlog();
```
